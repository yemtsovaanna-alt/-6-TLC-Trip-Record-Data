# dashboards/02-wav-accessibility/ — доступность поездок (WAV/AAR), FHVHV, 2025–2026

Отдельный аналитический трек по доступности поездок Uber/Lyft для пассажиров на
инвалидных колясках. Три флага в сырых данных FHVHV размечают сегменты:

- **WAV** (wheelchair-accessible vehicle) — машина технически приспособлена;
- **AAR** (accessible-assist request) — запрошено содействие водителя;
- **WAV request** — пассажир явно запросил доступный автомобиль.

Комбинация этих трех флагов дает 8 сегментов; базовый (обычная поездка без всех трех
флагов) — 90.99% всех поездок.

## Дашборд

**WAV/Accessibility Dashboard** — запись демонстрации: [`wav_dashboard.mp4`](wav_dashboard.mp4).
Сама Grafana-панель (JSON) в этом разделе не хранится — только исходные витрины и
ноутбуки, которыми она построена и обоснована.

## Проверенные гипотезы

1. **Использование WAV в часы высокого спроса** — поддерживается: в часы пик доля обычных
   поездок, выполненных на WAV-машине, выше на +0.567 п.п. (устойчиво после контроля
   ковариат в биномиальной регрессии).
2. **Различие времени ожидания** — инклюзивный сегмент ждет дольше: медиана +0.75 мин
   (bootstrap 95% CI [+0.75; +0.75]), p95 +1.00 мин.
3. **Различие временных паттернов спроса** — подтверждается линейной моделью (см. ноутбук
   для деталей коэффициентов).

Ключевой вывод: accessibility-сегмент мал относительно всего рынка (WAV request + AAR без
WAV request вместе — 0.3737% завершенных поездок), но именно поэтому ожидание и качество
подачи в этом сегменте — то, что стоит мониторить отдельно на дашборде.
